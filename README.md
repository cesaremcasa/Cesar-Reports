## About

This repository hosts HTML-based executive dashboards for internal use.  
Reports are generated from experiment data and pipeline analytics.

## How to Add a New Report

1. Add the new `.html` file to this repository
2. Push to `main` branch
3. It will be live at `https://cesaremcasa.github.io/Cesar-Reports/your-file.html`
4. Update the table above with the new report link

## Stack

- Pure HTML / CSS / JS — no framework dependencies
- Hosted on GitHub Pages (free)
- Auto-deploys on every push to `main`
